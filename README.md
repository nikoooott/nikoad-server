# ТВЕРЬ • Social

Готовый MVP локальной социальной сети для жителей Твери.

## Что уже работает
- регистрация и вход;
- профили пользователей;
- загрузка фотографий до 8 МБ;
- общая лента;
- лайки;
- комментарии;
- подписки;
- адаптивный интерфейс для телефона;
- SQLite база данных;
- сессии пользователей.

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm start
```
Открой http://localhost:3000

Для продакшена обязательно задай переменную `SESSION_SECRET` и используй постоянное хранилище для SQLite и `public/uploads`.
